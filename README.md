# 闲坐 XianReverie

[中文](#中文) | [English](#english)

## 中文

**闲坐 XianReverie** 是一个安静的个人角落——不联网、无账号、无分享。一片水墨山水，一道缓缓移过的光影。你可以每天留下一句话（也可以不留），它会回赠你一句古诗或祝愿。

### 特色

- 🌄 **八幅水墨山水背景**：斜阳、明月、竹林、古刹、孤舟、听松、云海、渔火，随心切换
- 🌗 **光影三种**：斜线 / 落叶 / 无，速度可调
- ✍️ **每日一帧**：想写了留一句，不想写就纯看景
- 📜 **软件回响**：写完回车，回赠一句古诗或祝愿（50 句，含作者与解读）
- 🌐 **中英双语**：界面、回响诗句、解读全双语
- 💾 **本地保存**：数据只存你的浏览器，开发者无法访问
- 🖼️ **导出图片**：把此刻的画面合成 PNG 下载

### 玩法

- 单击屏幕：写下今日一帧
- 回车：保存，软件回赠一句
- 双击（或菜单「回看往日」）：翻看过去的日子
- 右上角 ☰：背景 / 光影 / 光速 / 导出 / 说明
- 右上角 EN / 中文：切换语言

### 免责声明

本软件仅供个人静心、记录与娱乐，不含任何占卜、预测、迷信内容，不涉及任何商业、社交或数据收集功能。所有数据仅保存在本地浏览器，开发者无法访问。回响诗句整理自公开文献，仅供参考。

### 技术说明

纯 HTML / CSS / JavaScript 单页应用，无后端、无框架、无依赖。数据存于 localStorage。背景图位于 `generated-images/` 目录（分发时需与 `index.html` 一并携带）。

## English

**XianReverie** (闲坐, "sitting idle") is a quiet personal corner — no network, no account, no sharing. An ink-wash landscape, a slowly drifting light. You may leave one line a day (or none), and it answers with a classical verse or a wish.

### Features

- 🌄 **Eight ink-wash landscapes**: sunset, moon, bamboo, temple, lone boat, pines, sea of clouds, fishing lights
- 🌗 **Three light moods**: drifting beam / falling leaves / none, with adjustable speed
- ✍️ **One frame a day**: write a line if you wish, or simply watch the scene
- 📜 **A verse in return**: press Enter and it answers with a poem or a wish (50 items, with author and note)
- 🌐 **Bilingual**: UI, verses and notes in both Chinese and English
- 💾 **Local only**: all data stays in your browser; the developer cannot access it
- 🖼️ **Export**: compose the current scene into a PNG to download

### How to use

- Tap the screen: write today's line
- Press Enter: save it, and a verse echoes back
- Double-tap (or "Memory" in the menu): review past days
- Top-right ☰: scene / light / speed / export / help
- Top-right EN / 中文: switch language

### Disclaimer

For personal reflection and enjoyment only. It contains no divination, prediction or superstition, and has no commerce, social or data-collection features. All data stays in your local browser. Verses are compiled from public sources for reference.

### Technical notes

A single-page HTML / CSS / JavaScript app — no backend, no framework, no dependencies. Data is stored in localStorage. Background images live in `generated-images/` (keep them together with `index.html` when distributing).
